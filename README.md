# EV Market Performance & Insights

## Project Overview
This project analyzes an Electric Vehicle (EV) market dataset using Tableau Public. It explores EV manufacturers, vehicle categories, annual sales, customer ratings, battery technologies, driving range, and manufacturing countries.

**Note:** The dataset used in this project is synthetic and is intended for analytical and educational purposes.

## Objectives
- Analyze EV manufacturers and vehicle categories.
- Explore annual EV sales trends.
- Compare customer ratings across EV categories.
- Examine battery technology distribution.
- Explore the relationship between battery capacity and driving range.
- Visualize EV distribution by manufacturing country.

## Tools & Technologies
- Tableau Public
- Microsoft Excel / CSV
- GitHub
